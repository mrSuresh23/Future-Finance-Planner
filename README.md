# Future Finance Planner 💰

**Plan smarter today. Build a better financial future.**

Future Finance Planner is a web-based financial planning application designed to help users understand their financial position, project future wealth, and assess retirement readiness. It combines financial simulations, tax calculations, customizable life events, and AI-generated financial insights in one platform.

###  Key Features

*  **Future Wealth Projection** — Visualize projected wealth over time.
*  **Retirement Readiness** — Compare projected wealth with the required retirement corpus.
*  **Custom Life Events** — Explore the financial impact of salary increases and additional expenses.
*  **Tax Calculator** — Estimate taxes under the old and new tax regimes.
*  **AI Financial Insights** — Generate financial narratives using Google Gemini.
*  **User Authentication** — Register and log in to the application.
*  **Financial History** — Save and retrieve financial planning results.

###  Built With

`HTML` · `CSS` · `JavaScript` · `Java 17` · `Spring Boot` · `MySQL` · `Spring Data JPA` · `Google Gemini API` · `Maven`

### Project Goal

To make personal financial planning more accessible by combining financial projections, retirement planning, tax estimation, and AI-powered explanations in a single application.

### How to Run
* Install Java 17, Maven, and MySQL.
* Configure database credentials and the Gemini API key.
* Run the application:
    - mvn spring-boot:run
* Open http://localhost:8080.
